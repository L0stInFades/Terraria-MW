# 验证快照

这些是开发期间实际生成的报告快照，保留用于比较数值和检查已有行为。它们不是 GitHub CI 自动生成的结果；后续修改应重新运行相应验证，不能仅凭旧报告判断新版本通过。

| 文件 | 验证版本与范围 |
| --- | --- |
| `balance-1.2.0.json` | 原版参照与 24 把枪的 30 秒原生采样、完整弹匣长期输出 |
| `million-health-1.2.0.json` | 百万满血、84 防、600 像素、每两发故意打偏一发的固定目标校准 |
| `ciws-server-1.3.0.json` | 53 项炮塔、平台、伤害、目标顺序、物品保护和服务器验证 |
| `ciws-reload-1.3.0.json` | 4 项独立进程重载验证 |
| `ciws-client-1.3.0.json` | 15 项真实客户端验证，包括六座炮塔各 750 发 / 600 刻，以及四柱原生破盾和击杀顺序 |
| `flight-1.3.1.json` | 原版飞行饰品效果、无限飞行标志与角色保存重载 |

每个版本的原始报告内容不做强度或范围扩张：固定目标不等同于完整首领实战，自动客户端不等同于真人多人联机。原始本地存档、完整日志和反编译参考不在仓库中。
