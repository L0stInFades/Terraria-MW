# 真实改件参考与简易改枪玩法

选中一把枪，按 **V** 打开改枪界面。三个主选项是消音器、白光手电和瞄准模块，免费开关，独立保存在每把枪上；不需要制作配件。停止开火并完成换弹后可进入改装。界面打开时不能开火，切枪自动关闭。

| 游戏选项 | 已核对的实物资料 | 游戏效果 |
| --- | --- | --- |
| 消音器 | [SureFire SOCOM556-RC2](https://www.surefire.com/socom556-rc2/)、[Dead Air Wolverine PBS-1](https://deadairsilencers.com/silencers/wolverine-pbs-1/) | 枪口出现筒形改件；枪声衰减、枪口焰缩小，仍保留声音与微弱闪光；不扣伤害 |
| 白光手电 | [SureFire X300U-A](https://www.surefire.com/x300u-a/)、[M600U Scout Light](https://www.surefire.com/m600u-scout-light-weaponlight/) | 手枪导轨灯 / 长枪灯的轮廓参考；选中枪械即照亮前方，无需开火；光线被实体墙阻挡 |
| 可见激光 | [SureFire X400T-A](https://www.surefire.com/x400t-a-weaponlight/) 的红 / 绿可见激光通道 | 瞄准模块第一次点击进入红色可见瞄准线，显示墙面落点 |
| 红外瞄准 | [SureFire XVL2](https://www.surefire.com/xvl2-weaponlight/) 的可见 / IR 双通道 | 再次点击进入红外模式；未戴夜视装备时不显示；佩戴原版夜视头盔后显示夜视中的瞄准线，再点击关闭 |

现实中白光照明、可见激光、红外激光、红外泛光不是同一功能。XVL2 官方资料明确区分绿色可见激光、IR 激光、白光与 IR 照明；游戏用 X400 类可见激光和 XVL2 类 IR 瞄准作为简化的两个模式，没有把红线称作肉眼可见的“红外”。本版实现 IR 瞄准，白光照明独立开关。

夜视头盔可在界面中免费领取，放入头部护甲栏后生效。只领取到背包不会开启夜视；这条操作要求也会在界面说明。可见 / IR 互斥，白光灯和消音器可以独立组合。

官方产品照片的原始链接保存在 `attachment-reference/sources.json`；本地研究拼板与网页抓取不随仓库上传。

原始厂商页面及官方照片保存在 `attachment-reference/`，游戏内器件由代码独立绘制，没有直接缩图当作改件素材。游戏采用统一挂载适配，适配范围是玩法设定，外形参考不表示所有实枪型号可以直接互换。例如 Barrett 的 QDL 应与其官方列出的型号资料区分，不能据此把它写成任何 M82 的通用标准件。

现实中的其他常见改件还有红点 / 全息 / 倍率瞄具、前握把、枪托、弹匣、两脚架、枪口制退器及消焰器。本版保持三个主选项，先完成持枪、开火、换弹、照明、瞄准和保存的完整循环。
