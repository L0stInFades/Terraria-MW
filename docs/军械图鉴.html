装备与进度

新兵 → 克眼 → 邪恶首领或骷髅王 → 困难模式 → 任一机械首领 → 世纪之花。枪械与弹药均从补给箱按进度免费领取。R 换弹；弹药栏优先；切枪取消装填。用完弹匣后可改装其他兼容弹种。

弹药与弹道
