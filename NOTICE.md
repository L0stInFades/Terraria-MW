# Project and reference materials

Terraria: MW is an independent Terraria / tModLoader mod. Its internal mod name is `ModernArsenal`. It is not affiliated with Re-Logic, Activision, firearm manufacturers, or the creators of optional companion mods.

This repository contains the mod source, authored pixel assets, data, asset-generation tools, and documentation. Terraria and tModLoader must be installed separately; game binaries, decompiled game code, other authors' mod packages, personal worlds, and characters are not included.

Weapon and attachment research retains source links in `docs/reference/sources.json`, `docs/attachment-reference/sources.json`, and the reference documents. Downloaded third-party photos, webpage captures, and photo-derived pixel studies remain local and are excluded from Git. External linked images retain their respective owners' rights. Screenshots illustrate the mod running in Terraria.

No open-source license has been assigned to this project. Adding one is a repository-owner decision; the absence of a license is not a grant of redistribution rights.
